# AI Lost & Found: frontend

React 19 + Vite + Tailwind CSS v4 client for the AI Lost & Found API.

```bash
npm install
cp .env.example .env   # VITE_API_URL=http://localhost:8000
npm run dev            # http://localhost:5173
npm run lint
npm run build
```

See the [main README](../README.md) for the full project overview, architecture and backend setup.
